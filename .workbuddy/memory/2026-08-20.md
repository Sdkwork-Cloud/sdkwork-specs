## SDKWork PC 双宿主（Tauri + Electron）架构审查与设计

- **任务**：检查 PC 应用架构对 Tauri + Electron 双宿主的支持，产出完整设计与优化。
- **现状结论（Gap 分析）**：
  - 声明层已承认双宿主：`APP_MANIFEST_SPEC.md` L178-179 规范值含 `tauri`/`electron`；`CONFIG_SPEC.md` L204-210 `SdkworkDesktopConfig.nativeHost` 含 `electron`；拓扑 schema v5 `clientArchitectures` enum 含两者。
  - 架构层仅 Tauri 有 Profile：`DESKTOP_APP_ARCHITECTURE_SPEC.md` 只有 §5 Tauri Host Profile；Electron 无 main/preload/IPC/打包/安全基线定义。
  - 打包器 `tools/lib/app-publish/packagers/pc.mjs` L113 硬编码 `src-tauri/target/release/bundle`，不认 Electron 产物。
  - 桥接层只有能力分类列表（`APP_CLIENT_ARCHITECTURE_ALIGNMENT_SPEC.md` §9），无统一接口契约/IPC 协议/能力检测协议。
- **核心设计**：
  - 统一契约 `@sdkwork/desktop-host-contract`：`DesktopHost` 接口（window/tray/deepLinks/notifications/filePicker/filesystemSandbox/clipboard/secureStorage/updater/localRuntime + `hasCapability`），错误码 `unsupported/permission-denied/unavailable/cancelled/invalid-state/internal`。
  - 统一 IPC 协议：`sdkwork:<capability>:<action>` 三段式 method、`BridgeRequest/BridgeResponse/BridgeEvent` 消息形状；Tauri 用 invoke+Rust commands，Electron 用 contextBridge+ipcRenderer（preload 白名单），Browser 为降级实现。
  - Electron Host Profile：`sdkwork-<application-code>-pc-electron` 包（`src-electron/main|preload|shared` + `electron-builder.yml`），安全基线 `contextIsolation=true/nodeIntegration=false/sandbox=true`。
  - TypeScript 一致性：三实现 `satisfies DesktopHost` 编译期强制 + parity 测试。
  - 打包器按 `clientArchitecture` 分派 tauri/electron 产物；新增 `check:electron-config`；pnpm 别名映射 `['electron','desktop']`。
  - 默认宿主保持 `tauri`（向后兼容），`pnpm dev:desktop:electron` 显式选择。
- **交付物**：`docs/architecture/tech/DESKTOP_DUAL_HOST_DESIGN.md`（12 章：Gap 分析/目标架构/契约/桥接协议/TS 一致性/Electron Profile/打包/验证/规范修改清单/迁移路径/验收清单/ADR）。
- **建议后续**：按 §9.2 修改清单落地到 `DESKTOP_APP_ARCHITECTURE_SPEC.md` 等 spec 文件，再实施阶段 1（契约包）。
